# Changelog

## v0.2 — Interactive exploration release
- Added Rainfall Explorer with date selection, daily/monthly/monsoon views and CSV export.
- Added district comparison for up to five districts using NASA POWER point queries.
- Added Monsoon Scenario Lab with clearly labelled hypothetical rainfall multiplier.
- Added on-demand Serper Earth Intelligence Search.
- Improved monthly and seasonal completeness rules.
- Added tie correction to Mann–Kendall and actual-year spacing for Sen's slope.
- Added evidence/provenance visibility and refreshed deployment documentation.
- Preserved the existing Streamlit app structure and district boundary asset.
